Meeting Management

Stop losing the decisions taken in your meetings. This module records the agenda and the minutes of every meeting, keeps the list of attendees, and turns the follow-up points into real tasks that somebody owns and somebody chases.

Those follow-up tasks are ordinary project.task records, so they appear in the Project app with all of its kanban, calendar, deadline and timesheet features. There is no second task model to maintain and no data locked inside a custom screen.

Key Features

  • Meeting register with an automatic reference such as Meet/2026/09/0001.
  • Rich text Agenda and Meeting Minutes on every meeting.
  • Attendees picked from your employees, shown with the employee avatar widget.
  • One click email of the agenda and the minutes to every attendee, using their work email.
  • Files attached to the meeting are attached to that email automatically.
  • The email body is a standard mail.template, so you can restyle it without touching code.
  • Follow-up tasks created straight from the meeting, on Odoo's own project.task model.
  • Tasks open in a clean popup, both when adding a line and when editing an existing one.
  • Smart Status that tells a task finished on time apart from one finished late.
  • Overdue work sorts to the top of the list, so the next follow-up meeting starts where it should.
  • A daily scheduled action keeps the Smart Status honest as dates pass.
  • Meeting, employee and Smart Status filters and group by options added to the Project search view.
  • Full chatter on meetings, with change tracking on the title, date and attendees.
  • Depends only on core Odoo apps. No configuration needed.

How It Works

1. Open the Meeting app and create a meeting

Set the title and the date, pick the attendees, and write the agenda. The meeting reference is generated for you.

2. Write the minutes while the meeting runs

The minutes field is a full rich text editor, so headings, lists and tables all survive.

3. Add the follow-up tasks in the Tasks tab

Add a line opens a popup with the task title, the owner, the deadline and the progress. Each task stays linked to the meeting it came from.

4. Email the minutes to everybody who was there

Send Email builds one message per meeting, addressed to the work email of every attendee, with the meeting attachments included.

5. Chase the open points from one list

Smart Status

The stage of a task tells you what somebody set. Smart Status tells you what actually happened, by reading the deadline and the completion date together with the state.

Smart Status Meaning
Delayed Still open and the deadline has passed.
In Progress Work has started and the deadline is still ahead.
Not Started Nobody has picked it up yet and the deadline is still ahead.
Done Closed on or before the deadline.
Done Delayed Closed, but after the deadline. The one your follow-up meeting needs to see.
Cancelled Dropped.

A stored field cannot notice that today has moved on by itself, so a scheduled action named Meeting: Refresh Task Smart Status recomputes the open tasks once a day.

Technical Notes

  • Developed using the Odoo 20 framework.
  • Depends on mail, hr and project only. No third party or custom module needed.
  • One new model, hr.meeting, with mail.thread for chatter and tracking.
  • Follow-up tasks extend project.task. No parallel task model is introduced.
  • The core Project form, list and search views are extended by inheritance, not replaced.
  • Meeting numbering uses a standard ir.sequence, so you can change the format from the interface.
  • HR Officers get full rights on meetings. Every other internal user gets read only.
  • Installs on Community and Enterprise alike.
